# SEO House — القالب 2.7.8 + Core 2.7.7: ملفات التثبيت

**هذه الجولة (عنوان الشركة المنظم وصورتها في Schema):** تغيّرت حزمة Core فقط. Core تبقى المصدر الوحيد للبيانات المنظمة. ارفع `seohouse-core.zip` بـ«استبدال الحالي بالمرفوع». حزمة القالب هي نفسها 2.7.8 المرفوعة سابقًا؛ لا حاجة لرفعها مرة أخرى.

| الملف | الإصدار | يُرفع؟ |
|---|---|---|
| `seohouse-core.zip` | SEO House Core **2.7.7** | **نعم**: address كـPostalAddress من حقول «العنوان المنظم»، وimage للشركة، وحقول جديدة في «بيانات الشركة» |
| `seohouse-theme.zip` | قالب SEO House **2.7.8** | لا (بلا تغيير؛ نفس الملف بايتًا ببايت) |

- البصمات في `SHA256SUMS.txt`. تقرير الجولة والحقول المطلوب تعبئتها في `docs/round-core-2.7.7-org-address-image.md`، والاختبارات في `docs/qa-runs-core-2.7.7/`. آلية الإخراج المستقلة في `docs/round-core-2.7.6-schema-independent.md`. الأنواع والحقول المطلوب مراجعتها وروابط أدوات جوجل في `docs/round-core-2.7.5-schema.md`.
- مختبَر من الحالة المثبّتة: القالب 2.7.7 + Core 2.7.3 ← القالب 2.7.8 + Core 2.7.7، مع ACF 6.3.12 وRank Math 1.0.279 (وحدة Schema متوقفة، وتعمل، وRank Math معطّلة).

## ترتيب الرفع

1. خذ نسخة احتياطية (نسخة فقط، لا استيراد).
2. «الإضافات ← أضف جديد ← رفع إضافة» ← `seohouse-core.zip` ← **«استبدال الحالي بالمرفوع»**.
3. أفرغ كاش الموقع والـCDN.
4. لا تشغّل التهيئة ولا استيراد المحتوى.

## بعد الرفع

- املأ «إعدادات سيو هاوس ← بيانات الشركة ← العنوان المنظم للبيانات المنظمة»: الشارع والمنطقة «234 شارع عبد السلام عارف، لوران»، المدينة «الإسكندرية»، المحافظة «الإسكندرية»، رمز الدولة «EG». اترك الرمز البريدي فارغًا حتى تتأكد منه. ثم احفظ وأفرغ الكاش.
- اختياري موصى به: اختر «صورة الشركة في البيانات المنظمة» (علامة الشركة بمقاس 512×512 فأكثر).

- مصدر الصفحة الرئيسية يجب أن يحتوي `class="seohouse-schema"` مرة واحدة.
- «إعدادات سيو هاوس ← فحص البيانات المنظمة» ← «افحص الآن»: مصدر الإخراج، وغياب السكيما أو تكرارها في صفحات العينة، وبيانات الشركة المطبوعة، وقيم الشركة المحفوظة في Rank Math فقط (للنقل اليدوي)، والحالات التي تحتاج قرارك. لا يغيّر شيئًا.
- لا داعي لتشغيل وحدة Schema في Rank Math.

# SEO House — القالب 2.7.5 + Core 2.7.2: ملفات التثبيت

**جولة SEO (2.7.5، تحل محل 2.7.4):** القالب وحده تغيّر. إن كانت Core 2.7.2 مثبّتة فارفع `seohouse-theme.zip` فقط. القيم المطلوب إدخالها يدويًا، وقائمة التعديلات الملغاة، في `docs/seo-round-2.7.5.md`.


| الملف | الإصدار | يُرفع؟ |
|---|---|---|
| `seohouse-core.zip` | SEO House Core **2.7.2** (المثبّت الآن 2.7.1) | **نعم، أولًا**: إظهار حقل رابط المراجعات، والرابط العام، والهاتف المحلي، وتنظيف لوحة الإعدادات، وفحص الصور |
| `seohouse-theme.zip` | قالب SEO House **2.7.5** (hreflang، وبلوك «خدماتنا في الأسواق العربية»، ورابط نبذة الفوتر، وسطر المقال) | **نعم، ثانيًا**: نموذج بخطوة واحدة، والهيدر الثابت، وتوسيط الخدمات، وزر المراجعات في كل الصفحات |

- البصمات في `SHA256SUMS.txt`. التقرير في `docs/review-2.7.3.md`، والاختبارات واللقطات في `docs/qa-runs-2.7.3/`.
- مختبَر من الحالة المثبّتة: القالب 2.7.2 + Core 2.7.1 + ACF 6.3.12 + Rank Math 1.0.279، مع محتوى معدّل وطلبات سابقة وحجز مؤكد وآخر غير متحقق، وإعدادات Calendly محفوظة.

## ترتيب الرفع

1. خذ نسخة احتياطية (نسخة فقط، لا استيراد).
2. «الإضافات ← أضف جديد ← رفع إضافة» ← `seohouse-core.zip` ← **«استبدال الحالي بالمرفوع»**.
3. «المظهر ← قوالب ← أضف جديد ← رفع قالب» ← `seohouse-theme.zip` ← **«استبدال الحالي بالمرفوع»**.
4. أفرغ كاش الموقع والـCDN.
5. لا تشغّل التهيئة ولا استيراد المحتوى.

## بعد الرفع

- **رابط المراجعات:** «تحرير الصفحة الرئيسية ← التقييمات ← رابط جميع المراجعات على Google»، أو الرابط العام في «إعدادات سيو هاوس ← تقييمات جوجل».
- **فحص الصور:** افتح «الوسائط ← SEO-House-Icon-2.webp ← تعديل المزيد من التفاصيل»، وأرسل لي صورة صندوق «فحص الصورة» إن بقيت مشكلة.

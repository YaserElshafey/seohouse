## ترتيب الرفع

1. خذ نسخة احتياطية (نسخة فقط، لا استيراد).
2. «الإضافات ← أضف جديد ← رفع إضافة» ← `seohouse-core.zip` ← **«استبدال الحالي بالمرفوع»**.
3. «المظهر ← قوالب ← أضف جديد ← رفع قالب» ← `seohouse-theme.zip` ← **«استبدال الحالي بالمرفوع»**.
4. **امسح كاش الموقع والـCDN.**
5. لا تشغّل التهيئة ولا استيراد المحتوى.

## بعد الرفع

- ادخل لوحة التحكم مرة كمدير، ثم **امسح الكاش**، ثم «إعدادات سيو هاوس ← فحص البيانات المنظمة ← افحص الآن»: جدول الخرائط يجب أن يظهر «مفعّل (محفوظ)» و«HTTP 200» و«في الفهرس: نعم» للفريق ودراسات الحالة. ثم أعد إرسال sitemap_index.xml في Search Console.

- «الصفحات ← تحرير تحسين محركات البحث (/services/seo/) ← نتائج موثقة من مشاريع السيو ← الحالات»: في كل بطاقة اختر **«دراسة الحالة لهذه البطاقة»** (تحت «نص الرابط»)، أو اتركه فارغًا لإخفاء الرابط. ثم «تحديث» و**امسح الكاش**.
- إن لم تُدخل بعد «العنوان المنظم للبيانات المنظمة» في «إعدادات سيو هاوس ← بيانات الشركة»، فالقيم في `docs/round-core-2.7.7-org-address-image.md`.

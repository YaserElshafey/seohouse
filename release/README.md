# SEO House — القالب 2.8.6 + Core 2.9.7: ملفات التثبيت

**هذه الجولة (النسخة الإنجليزية على /en/ مع Polylang):** الحزمتان منشورتان على الموقع مباشرة عبر `tools/deploy.sh`، ولا حاجة لرفع يدوي. التفاصيل وخطوات الإطلاق في `docs/round-2.9.0-english.md`.

| الملف | الإصدار | ما الجديد |
|---|---|---|
| `seohouse-core.zip` | SEO House Core **2.9.7** | ترجمة المقالات ودراسات الحالة والفريق، روابط إنجليزية بنفس هيكل العربي (/en/…)، بيانات الشركة القانونية (الفوتر والسكيما)، تحديث خريطة الموقع بعد الإطلاق، طبقة اللغتين (Polylang)، نصوص الإعدادات بالإنجليزي، مسارات REST للإعداد والاستيراد، البحث العربي يشمل دراسات الحالة والفريق (2.8.3: تصدير المحتوى للقراءة) |
| `seohouse-theme.zip` | قالب SEO House **2.8.6** | hreflang للمدونة والأقسام، سطر حقوق واحد بالاسم القانوني، أيقونات تواصل خطية، سطر السجل التجاري والرقم الضريبي في الفوتر، الاتجاه حسب اللغة، ترجمة نصوص القالب، زر اللغة AR/EN، قائمة بلا إطار، hreflang للإنجليزي بعد الإطلاق |

- البصمات في `SHA256SUMS.txt`. الجولة السابقة: `docs/round-2.8.0-authors-deploy-audit.md`.
- **يتطلب:** إضافة Polylang (مثبتة ومفعّلة على الموقع). بدونها يبقى الموقع عربيًا كما كان.

## ترتيب الرفع

1. خذ نسخة احتياطية (نسخة فقط، لا استيراد).
2. «الإضافات ← أضف جديد ← رفع إضافة» ← `seohouse-core.zip` ← **«استبدال الحالي بالمرفوع»**.
3. «المظهر ← قوالب ← أضف جديد ← رفع قالب» ← `seohouse-theme.zip` ← **«استبدال الحالي بالمرفوع»**.
4. **امسح كاش الموقع والـCDN.**
5. لا تشغّل التهيئة ولا استيراد المحتوى.

## بعد الرفع

- ادخل لوحة التحكم مرة كمدير، ثم **امسح الكاش**، ثم «إعدادات سيو هاوس ← فحص البيانات المنظمة ← افحص الآن»: جدول الخرائط يجب أن يظهر «مفعّل (محفوظ)» و«HTTP 200» و«في الفهرس: نعم» للفريق ودراسات الحالة. ثم أعد إرسال sitemap_index.xml في Search Console.

- «الصفحات ← تحرير تحسين محركات البحث (/services/seo/) ← نتائج موثقة من مشاريع السيو ← الحالات»: في كل بطاقة اختر **«دراسة الحالة لهذه البطاقة»** (تحت «نص الرابط»)، أو اتركه فارغًا لإخفاء الرابط. ثم «تحديث» و**امسح الكاش**.
- إن لم تُدخل بعد «العنوان المنظم للبيانات المنظمة» في «إعدادات سيو هاوس ← بيانات الشركة»، فالقيم في `docs/round-core-2.7.7-org-address-image.md`.

## ترتيب الرفع

1. خذ نسخة احتياطية (نسخة فقط، لا استيراد).
2. «الإضافات ← أضف جديد ← رفع إضافة» ← `seohouse-core.zip` ← **«استبدال الحالي بالمرفوع»**.
3. «المظهر ← قوالب ← أضف جديد ← رفع قالب» ← `seohouse-theme.zip` ← **«استبدال الحالي بالمرفوع»**.
4. أفرغ كاش الموقع والـCDN حتى يظهر حقلا البريد والهاتف. الصفحات المخزّنة بالنموذج القديم تبقى مقبولة إلى أن يُفرَغ الكاش.
5. **لا تشغّل «تهيئة الموقع» ولا «تجهيز المحتوى» ولا «تحديث محتوى التصميم».** التحديث لا يكتب أي محتوى.

## ربط الحجز (عند توفر حساب Calendly)

من «إعدادات سيو هاوس ← الاستشارة»:

1. **أداة الحجز:** Calendly.
2. **رابط التضمين:** رابط نوع حدث مدته 30 دقيقة، مثل `https://calendly.com/<الحساب>/30min`.
3. **مدة المكالمة:** 30.
4. **رمز Calendly API:** من Calendly: Integrations ← API & Webhooks ← Personal Access Tokens.
5. في Calendly: اترك «Redirect to an external site» مطفأ.

حتى يتم الربط تبقى الخطوة الثانية «تم إرسال الطلب» برسالة التواصل الحالية.

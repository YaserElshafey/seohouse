## الرفع على الموقع الأساسي

1. خذ نسخة احتياطية (نسخة فقط، لا استيراد).
2. «المظهر ← قوالب ← أضف جديد ← رفع قالب» ← `seohouse-theme.zip` ← **«استبدال الحالي بالمرفوع»**. يحذف هذا ملفات القالب القديم المتبقية في المجلد (`front-page.php.old` وغيره).
3. أفرغ كاش الموقع إن وُجد.
4. **لا ترفع الإضافة، ولا تشغّل «تهيئة الموقع» ولا «تجهيز المحتوى».** التحديث لا يكتب أي محتوى.
5. اختياري: «إعدادات سيو هاوس ← الهوية ← الشعار على الخلفية الفاتحة» إن أردت شعارًا غير الأزرق الافتراضي في الهيدر.

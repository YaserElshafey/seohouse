## ترتيب الرفع

1. خذ نسخة احتياطية (نسخة فقط، لا استيراد).
2. «الإضافات ← أضف جديد ← رفع إضافة» ← `seohouse-core.zip` ← **«استبدال الحالي بالمرفوع»**.
3. «المظهر ← قوالب ← أضف جديد ← رفع قالب» ← `seohouse-theme.zip` ← **«استبدال الحالي بالمرفوع»**.
4. أفرغ كاش الموقع والـCDN (مهم لنموذج الرئيسية).
5. **لا تشغّل «تهيئة الموقع» ولا «تجهيز المحتوى».** التحديث لا يكتب أي محتوى.
6. بعد الرفع:
   - «تحرير الصفحة الرئيسية ← قسم المراجعات (تقييمات Google) ← رابط جميع المراجعات على Google»: الصق رابط صفحة المراجعات على Google Maps. (إن كان رابط Google Maps محفوظًا في «إعدادات سيو هاوس ← بيانات الشركة ← الروابط الاجتماعية» يُستخدم تلقائيًا.)
   - «إعدادات سيو هاوس ← الاستشارة ← بريد استلام الطلبات»: افتراضيًا info@seohouse.agency.
   - أرسل طلبًا تجريبيًا من الرئيسية وآخر من «اتصل بنا» وأنت غير مسجّل دخول، وتأكد من وصول البريد.

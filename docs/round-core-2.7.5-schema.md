# Core 2.7.5 — البيانات المنظمة (Schema)

**الحزمة المطلوبة:** `seohouse-core.zip` فقط (SEO House Core 2.7.5). القالب 2.7.8 بلا تغيير، وحزمته في `release/` هي نفسها السابقة بايتًا ببايت.

**نقطة البداية:** القالب 2.7.8 وCore 2.7.4، آخر نسخة على الفرع `claude/design-v5-rollout`، واجتازت GitHub Actions.

**طريقة التطبيق:**
- كل الإضافات عبر `rank_math/json_ld` داخل graph الخاص بـRank Math، دون سكربت مستقل ولا إضافة جديدة.
- لا تغيير في المحتوى المرئي ولا التصميم ولا الـslugs ولا H1 ولا العناوين والأوصاف ولا canonical ولا hreflang.
- لا تغيير في قاعدة البيانات.

**حدود الفحص:** تعذر الوصول إلى seohouse.agency من بيئتي، فسياسة الشبكة ترفض النطاق مع curl وWebFetch. كل الفحص على نسخة الاختبار المحلية: القالب 2.7.8 وCore 2.7.4، مع ACF 6.3.12 وRank Math المجاني 1.0.279 ومحتوى معدّل. **لم أتحقق من الموقع الحقيقي.**

## 1. الفحص قبل التعديل

### مصادر الإخراج

| المصدر | ما يخرجه |
|---|---|
| Rank Math | عقدة الشركة (`publisher`)، وWebSite بـSearchAction، وWebPage، وBlogPosting للمقالات، وImageObject لصورة المقال |
| Core `inc/rankmath.php` (`sh_rankmath_graph`) | يعدّل graph الخاص بـRank Math: نوع الصفحة، وBreadcrumbList الظاهر، وService، وItemList، وFAQPage، وPerson |
| Core `inc/schema.php` | graph كامل لـCore، يُستخدم فقط بلا إضافة سيو، أو للصفحات التي لا يخرج لها Rank Math شيئًا (دراسات الحالة وصفحات الأعضاء: إعداد Rank Math الافتراضي لها «بلا Schema») |
| القالب | لا يطبع أي Schema |
| إضافة التقييمات (Trustindex) | غير موجودة محليًا، فلم يمكن فحص إخراجها |

| BreadcrumbList | مسار التنقل الظاهر | كما هو |

### قواعد عامة في الكود
- **تكرار الكيانات:** العقد التي تحمل `@id` نفسه تُدمج في عقدة واحدة (قيمة Rank Math أولًا)، فلا يظهر الكيان مرتين ببيانات متعارضة.
- **الشركة في كل الصفحات:** الصفحات التي لا يطبع فيها Rank Math عقدة الشركة (الأرشيف يحذف شعاره، ودراسات الحالة والأعضاء بلا graph) تأخذ اسم Rank Math وشعاره وحساباته نفسها.
- **صفحات التجميع:** CollectionPage دائمًا (الخدمات، والقطاعات، والنتائج، والفريق، والمدونة)، و«بدون» يوقف البيانات المنظمة للصفحة. هذا يجعل `/services/` CollectionPage دون تعديل قيمة الحقل المحفوظة. التعليمات مكتوبة تحت الحقل.
- **sameAs:** روابط خرائط Google والاتجاهات والتضمين والمحادثة (واتساب وتيليجرام) وروابط الموقع نفسه لا تُعد حسابات.
- **إضافة التقييمات:** إن طبعت إضافة التقييمات JSON-LD فيه AggregateRating أو Review داخل الشورت كود، يُحذف هذا الـJSON-LD وحده ويبقى عرض التقييمات كما هو.
- **ما لا يُضاف:** SearchAction، وأي تقييم للشركة.
- **Person:** يُطبع للأعضاء المنشورين فقط. كل عضو ظاهر في `/team/` له صفحة منشورة، فلم يلزم معرّف `/team/#person-{id}`. العضو المحذوف أو المخفي لا يُطبع.

## 3. ما تملؤه أو تقرره

**أداة جديدة للموقع الحقيقي:** «إعدادات سيو هاوس ← فحص البيانات المنظمة».
- تقرأ الصفحة الرئيسية كما يراها الزائر، وتقارن بيانات الشركة المطبوعة بإعداداتك، وتعرض كل تعارض بدل اختيار قيمة بصمت، وتسرد الحالات أدناه.
- لا تغيّر شيئًا. شغّلها بعد الرفع: لا أعرف قيم Rank Math على موقعك.

| # | المكان | المطلوب |
|---|---|---|
| 1 | فحص البيانات المنظمة ← جدول الشركة | أي سطر «تعارض» (Rank Math يطبع قيمة غير الظاهرة في الموقع، مثل الهاتف): صحّح القيمة الخاطئة في Rank Math ← العناوين والوصف ← Local SEO أو في «إعدادات سيو هاوس». الكود لا يختار عنك. |
| 2 | تحرير المقال «هل يظهر موقعك داخل إجابات جوجل بالذكاء الاصطناعي؟…» ← «الكاتب» | **مرتبط بالعضو المحذوف (#50)**: يظهر «بقلم» بلا اسم، ولا يُطبع له مؤلف. اختر عضوًا منشورًا أو أفرغ الحقل (فيظهر «فريق سيو هاوس» ويصبح المؤلف الشركة). لم أغيّر العرض. |
| 3 | الهوية ← «الشعار على الخلفية الفاتحة» (أو شعار Rank Math) | الشعار الحالي 290×68، وGoogle يطلب 112×112 على الأقل. ارفع نسخة أكبر تظهر على خلفية بيضاء. لا تستخدم الشعار الأبيض. |
| 4 | تحرير «السيو في السعودية» ← «اسم الخدمة في Schema» | فارغ، فلا يُطبع serviceType. اقتراح: «تحسين محركات البحث». |
| 5 | «اسم الخدمة في Schema» في صفحتي مصر والإمارات | القيمة «خدمات تحسين محركات البحث» صحيحة، لكنها شبه مطابقة لصفحة السيو العامة («تحسين محركات البحث»). وحّدها إن أردت؛ areaServed يميّز كل صفحة. |
| 6 | دراسات الحالة الثلاث | بلا صورة بارزة وبلا لقطات موثقة محليًا، فلا يُطبع image. أضف صورة بارزة حقيقية إن وُجدت على موقعك. |
| 7 | إعدادات إضافة التقييمات (Trustindex) | إن كان فيها خيار Schema/Rich snippet فأوقفه. الفحص ينبهك إن وُجد AggregateRating أو Review في الصفحة. |
| 8 | «روابط التواصل في الفوتر» | الفحص يسرد أي رابط مستبعد من sameAs، مثل رابط خرائط Google. رابط ملف النشاط على Google لم أعدّه حسابًا؛ أخبرني إن أردت إضافته. |
| 9 | areaServed لخدمات المواقع والمتاجر والقطاعات | لم أضفه لعدم وجود نطاق موثق لكل خدمة. نطاق الشركة (الدول الثلاث) موجود على Organization. |

## 5. ما تختبره بعد الرفع

أفرغ الكاش أولًا، ثم شغّل «فحص البيانات المنظمة».

**[Schema Markup Validator](https://validator.schema.org/)** (يقبل كل الأنواع، ومنها Service وCollectionPage). تأكد أن لا أخطاء، وأن عقدة واحدة فقط بمعرّف `https://seohouse.agency/#organization`:

| https://seohouse.agency/contact/ | ContactPage |
| https://seohouse.agency/services/ | CollectionPage + ItemList |
| https://seohouse.agency/sectors/ | CollectionPage + ItemList |
| https://seohouse.agency/results/ | CollectionPage + ItemList |
| https://seohouse.agency/blog/ | CollectionPage + ItemList |
| https://seohouse.agency/team/ | CollectionPage + ItemList |
| https://seohouse.agency/services/seo/ | Service، وareaServed ثلاث دول |
| https://seohouse.agency/services/seo/ksa/ | Service، السعودية فقط |
| https://seohouse.agency/services/seo/egypt/ | Service، مصر فقط |
| https://seohouse.agency/services/seo/uae/ | Service، الإمارات فقط |

| صفحة عضو، مثل https://seohouse.agency/team/yasser-youssef/ | ProfilePage + Person |

**[Rich Results Test](https://search.google.com/test/rich-results):**
- **المقال:** نتيجة «Article» صالحة.
- **دراسة الحالة:** قد تظهر تحذيرات عن الصورة إن كانت بلا صورة.
- **الرئيسية:** «Organization» إن عرضها.
- **صفحة فيها أسئلة:** قد يظهر FAQ في الأداة، لكن جوجل لا يعرضه حاليًا لمعظم المواقع.
- **Service وCollectionPage:** عدم ظهورهما في هذه الأداة طبيعي ولا يعني خطأ.

**كيف تقرأ النتائج:**
- **عقدتان للشركة أو معرّف غير `/#organization`:** أرسل لي لقطة.
- **AggregateRating في أي صفحة:** المصدر غالبًا إضافة التقييمات خارج الشورت كود. أوقف خيار Schema فيها.

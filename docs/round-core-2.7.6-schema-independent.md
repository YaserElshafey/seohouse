# Core 2.7.6 — سكيما مستقلة من SEO House Core

**الحزمة المطلوبة:** `seohouse-core.zip` (SEO House Core 2.7.6) فقط. القالب 2.7.8 بلا تغيير، وحزمته في `release/` هي نفسها بايتًا ببايت.

**القرار الجديد:** Core هي المصدر الوحيد للسكيما. هذا يحل محل شرط الإضافة عبر `rank_math/json_ld` في جولة 2.7.5. أنواع السكيما والعلاقات والمعرّفات المتفق عليها في `docs/round-core-2.7.5-schema.md` لم تتغير، وكذلك قائمة الحقول المطلوب مراجعتها.

## ما تغيّر

| | Core 2.7.5 | Core 2.7.6 |
|---|---|---|
| من يطبع السكيما | Rank Math، وCore تكمّل graph الخاص به. **مع وحدة Schema متوقفة (وضع موقعك) لا يُطبع أي JSON-LD** | **Core وحدها:** مخطط واحد كامل في `wp_head` بـ`class="seohouse-schema"`، سواء كانت Rank Math مفعّلة أو لا، ووحدة Schema متوقفة أو تعمل |
| شرط «عدم وجود إضافة SEO» | كان يوقف مخطط Core عند تفعيل Rank Math | أُلغي. يبقى الفلتر `sh_schema_enabled` للإيقاف اليدوي فقط |
| إضافة العقد إلى graph الخاص بـRank Math | `sh_rankmath_graph()` وما يتبعها | **حُذفت** |
| JSON-LD الخاص بـRank Math إن شُغّلت وحدة Schema لاحقًا | يُطبع | **لا يُطبع.** فلترها الموثق `rank_math/json_ld` يعيد مصفوفة فارغة في آخر ترتيب، في صفحات الموقع فقط، فلا تطبع Rank Math الـscript. لا حذف عام لسكربتات الصفحة، ولا تعطيل لـ`rank_math/head`، ولا تغيير في إعدادات Rank Math المحفوظة، ومعاينة Schema داخل لوحة التحكم تعمل كما هي |
| بيانات الشركة والشعار والمؤلفين | جزء منها من كائنات Rank Math الداخلية (`$jsonld`) | **من إعدادات سيو هاوس وحقول المحتوى فقط.** لا قراءة لكائنات Rank Math ولا دواله |
| اسم الصفحة ووصفها في WebPage | — | العنوان والوصف كما يطبعهما الـhead. Rank Math لا تزال تملك هذه الوسوم، فلا تُكرر بقيمة مختلفة |
| WebPage | — | أُضيف `datePublished` و`dateModified` الحقيقيان للصفحات والمقالات |
| شاشة «فحص البيانات المنظمة» | تقارن بيانات الشركة | تضيف مصدر الإخراج ووضع وحدة Schema، وتفحص 14 صفحة عينة: وجود مخطط Core مرة واحدة، وغياب السكيما، وتكرارها من مصدر آخر، وJSON غير صالح، وعدد عقد الشركة. وتعرض قيم الشركة المحفوظة في Rank Math فقط للنقل اليدوي |

**ما لم يتغير في Rank Math:**
- العنوان والوصف وcanonical وrobots وOpen Graph وTwitter وخرائط الموقع XML.
- مسار التنقل المرئي، وhreflang الحالي.

**ما يبقى ممنوعًا:**
- التقييمات الذاتية على الشركة: التقييمات المرئية باقية، وJSON-LD التقييم داخل شورت كود التقييمات يُحذف.
- SearchAction.
- أي بيانات مختلقة أو خصائص فارغة.

## قيم محفوظة في Rank Math فقط

لا تُستخدم في السكيما ولا تُنقل تلقائيًا. تجدها في «إعدادات سيو هاوس ← فحص البيانات المنظمة» ← «قيم الشركة المحفوظة في Rank Math»، ومعها مكان كل قيمة في سيو هاوس:
- **في Rank Math فقط:** انقلها يدويًا إن كانت معتمدة.
- **مختلف:** حدّد القيمة الصحيحة.

يقرأ الفحص إعدادات Rank Math المحفوظة للعرض فقط: الاسم، والشعار، والهاتف، والبريد، والعنوان، والحسابات.

**محليًا:** إعدادات Rank Math لا تحوي إلا الاسم «سيو هاوس»، وهو مطابق. في سيناريو شركة بقيم مختلفة عمدًا ظهرت الحالات الثلاث: «شعار في Rank Math فقط»، و«هاتف مختلف»، و«عنوان مختلف». لا أعرف قيم موقعك، فشغّل الفحص بعد الرفع.

## الاختبار (محلي — نسخة الاختبار، لا الموقع الحقيقي)

**الإعداد:** Rank Math 1.0.279 محليًا (موقعك 1.0.280)، وACF 6.3.12، والقالب 2.7.8. وحدة Schema محليًا تعمل؛ وضع «متوقفة» محاكى بإزالة `rich-snippet` من قائمة الوحدات عبر فلتر في الطلب نفسه، دون تغيير الإعداد المحفوظ.

| الحالة | السكيما | HTML قبل/بعد (30 صفحة) | فحص السكيما (27 صفحة) |
|---|---|---|---|
| Rank Math مفعّلة ووحدة Schema **متوقفة** (وضع موقعك) | قبل: **لا JSON-LD**. بعد: مخطط Core واحد في 29 صفحة (صفحة 404 بلا سكيما عمدًا) | **لا فرق خارج JSON-LD:** نفس العنوان والوصف وcanonical وrobots وOpen Graph وhreflang وكل الـHTML | 0 أخطاء |
| Rank Math مفعّلة ووحدة Schema **تعمل** | قبل: كتلة `rank-math-schema`. بعد: **كتلة `seohouse-schema` فقط**، بلا كتلة Rank Math ولا تكرار | **لا فرق خارج JSON-LD** | 0 أخطاء |
| Rank Math **معطّلة بالكامل** | مخطط Core يعمل بلا أخطاء PHP ولا اعتماد مفقود | لا فرق خارج JSON-LD | 0 أخطاء |

**عن مقارنة HTML:**
- تشمل الـhead والـbody كاملين بعد إزالة كتل JSON-LD.
- استُثنيت قيمتان تتغيران مع كل تحميل ولا علاقة لهما بالسيو: رقم نسخة `site.js` المأخوذ من وقت الملف، والطابع الزمني لحماية النماذج.

**ما يتحقق منه فحص السكيما:**
- JSON صالح، وكتلة واحدة، ولا `@id` مكرر.
- عقدة شركة واحدة Organization بمعرّف `/#organization`، وكل المراجع تُحل، ولا خصائص فارغة.
- لا SearchAction ولا تقييمات.
- الأنواع المتفق عليها: AboutPage، وContactPage، وCollectionPage + ItemList، وService بالاسم = H1 والوصف الظاهر وareaServed للدول، وBusinessAudience للقطاعات، وArticle للدراسة، وBlogPosting للمقال، وProfilePage + Person للعضو.
- عناصر القوائم وأسئلة FAQ ظاهرة في الصفحات.
- H1 والعنوان والوصف وcanonical وhreflang وrobots كما كانت.

**فحوص إضافية:**
- **شاشة الفحص:** كشفت التكرار عند محاكاة إضافة أخرى تطبع Organization، وكشفت الغياب عند إيقاف مخطط Core.
- **Rank Math بإعداد شركة بقيم مختلفة:** السكيما تأخذ قيم سيو هاوس وحدها، وقيم Rank Math تظهر في جدول النقل اليدوي.
- **الترقية من القالب 2.7.7 + Core 2.7.3 بالحزم النهائية:** قاعدة البيانات بلا تغيير، و63 رابطًا 200، ولا أخطاء PHP من سيو هاوس.
- **خرائط الموقع:** `sitemap_index.xml` و`page-sitemap.xml` من Rank Math تعمل.
- **النماذج:** الحفظ والتكرار وفشل الحفظ والبريد بسطر المصدر كما كانت.

**لم أشغّل Schema Markup Validator ولا Rich Results Test:** يحتاجان رابطًا عامًا، والموقع غير متاح من بيئتي. الروابط وما تتأكد منه في الجزء 5 من `docs/round-core-2.7.5-schema.md` تنطبق كما هي.

## بعد الرفع

1. ارفع `seohouse-core.zip` بـ«استبدال الحالي بالمرفوع»، ثم أفرغ كاش الموقع والـCDN.
2. افتح مصدر الصفحة الرئيسية: يجب أن تجد `<script type="application/ld+json" class="seohouse-schema">` مرة واحدة.
3. شغّل «إعدادات سيو هاوس ← فحص البيانات المنظمة ← افحص الآن»:
   - الصفحات كلها «سليم».
   - راجع جدول قيم Rank Math، وحالات المراجعة: الكاتب المحذوف، والشعار، و«اسم الخدمة في Schema» لصفحة السعودية، وصور دراسات الحالة.
4. لا داعي لتشغيل وحدة Schema في Rank Math، وإن شُغّلت لن تُكرر السكيما.
